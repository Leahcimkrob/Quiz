# Quiz

Ein kleines Quiz-Projekt, das während meiner Umschulung zum **Fachinformatiker für Anwendungsentwicklung** entstanden ist.

## 📋 Über das Projekt

Das Projekt dient dazu, Fragen mit mehreren Antwortmöglichkeiten zu stellen und die Antworten des Benutzers auszuwerten.

Dabei werden grundlegende Programmierkonzepte wie Benutzereingaben, Bedingungen, Schleifen und die Verarbeitung von Daten eingesetzt.

## 🎯 Ziel

Ziel des Projekts war es, praktische Erfahrungen bei der Entwicklung einer kleinen Anwendung zu sammeln und grundlegende Programmierkonzepte anzuwenden.

## 🛠️ Verwendete Technologien

* Java
* JSON
* Git & GitHub

## 📚 Was ich dabei gelernt habe

* Verarbeitung von Benutzereingaben
* Arbeiten mit JSON-Daten
* Kontrollstrukturen und Programmabläufe
* Entwicklung einer einfachen Quizlogik
* Fehlerbehandlung und Debugging
* Strukturierung eines kleinen Softwareprojekts
